Request Builder

Turn a request for any of your projects into a clear brief for Claude. A clear brief means fewer questions, less re-reading and a smaller job, so each request uses less of your API budget.

  1. 1Fill in the order
  2. 2Fix what the ticket flags
  3. 3Copy it or open a GitHub issue

1 Which projects? required

Tick every project the work touches. Art made for a project is always saved in Art Assets too.

2 What kind of request? required

3 In one sentence required

What you want, not how. "Lock 12's plate loses its letters on a phone", not "fix the locks".

4 Details

4b The art

Art is involved, so these come from the Art Asset Builder (now retired; old form). Leave anything blank and it is decided from research.

4c More to this task? optional

Split a big task into parts. Each part becomes its own ticket that shares everything else on this form (projects, area, job size, notes to read); the copy box holds the whole bundle, and each part can be opened as its own GitHub issue.

5 Size check: how big a job?

How much work you expect, which sets how far Claude may go. Smaller jobs use less. Not sure? Use the button at the bottom.

      Why these fields save API usage
        
 
      • One sentence and a type tell Claude what is being asked straight away, so no turn is spent on clarifying questions. Every extra turn re-reads the whole conversation.
        • 
 
      • Where in the project points Claude at the right file, so it doesn't search the repo first.
        • 
 
      • Done when sets a finish line, so the work stops when it's met instead of polishing.
        • 
 
      • How big a job and Leave alone stop changes from spreading into refactors you didn't ask for.
        • 
 
      • Before you start on the ticket tells Claude which project notes to read. They hold the decisions already made, so nothing gets worked out twice.
        • 
 
      • The art questions (shown when art is involved) used to be a separate form. One place means no art request starts in the wrong form, and when the research library already covers a subject the preview draws it here, with no Claude at all.
        • 
 
      • Sources to treat as expert stop Claude searching the web for facts you already trust.
        • 
 
      • One request per ticket keeps each job small and easy to check. The ticket flags a summary that looks like two requests.
